# Моды Herdr App: группы spaces и лимиты агентов

Две панели для боковой панели Herdr App. Это обычные моды Herdr App (JavaScript на gpui-kit в
`mods/<name>/` домашней папки приложения); в herdr-core они ничего не меняют.

## 1. Группы spaces (`herdr-app/space-groups`)

Штатный список `spaces` с папками. Всё штатное поведение сохраняется: аватары, worktree под своим
репозиторием, разделы по машинам, ветка git и опережение/отставание, меню space.

| Действие | Результат |
|---|---|
| Кнопка с папкой в заголовке Spaces | новая группа на машине показанного space |
| Перетащить space на группу | space попадает в группу, в конец |
| Перетащить space на space в группе | space встаёт перед ним или после него, по половине под указателем |
| Перетащить space на space вне групп | штатная перестановка (`space.move`) |
| Перетащить space ниже последней строки | space выходит из всех групп |
| Перетащить группу на середину / край группы | группа становится подгруппой / встаёт перед ней или после неё |
| Перетащить группу на space или ниже последней строки | в группу этого space / на верхний уровень |
| Щелчок по группе | свернуть или развернуть (аккордеон) |
| Правый щелчок по группе | переименовать, новая подгруппа, расформировать (spaces и подгруппы переходят к родителю) |

Строка группы показывает число spaces в ней, включая подгруппы, и самое срочное состояние агентов
внутри: индикатор вращения (работает), цветная точка (ждёт человека, завершил), полая точка (только
простаивающие агенты). Группа принадлежит одной машине; перетаскивание между машинами не
выполняется. Узкая панель остаётся плоским списком.

Группы являются представлением этого экрана. Они хранятся в общем состоянии приложения
(`shared("space-groups")`) и никогда не попадают в документ ядра `herdr-app`. Идентификаторы,
имена, папки и вкладки spaces не меняются, поэтому инструменты, находящие space по текущим
каталогам его терминалов (`tool_ask.py --space module`, `[workers] space = "project"` шаблона GSD),
работают одинаково с группами и без них. Исчезнувший space удаляется из группы, когда раскладка его
машины снова доступна.

## 2. Лимиты агентов (`herdr-app/agent-limits`, `limits.py`)

По одной строке на агента: значок, имя и каждое окно использования, о котором сообщает среда
(5 ч, 7 дней, месяц, предел расходов), в виде процента с тонкой полосой. Цвет следует за
использованием: зелёный, с 70 % цвет темы «работает», с 90 % цвет «ждёт человека». Подсказка окна
показывает использовано, осталось и время сброса; подсказка имени - возраст данных; щелчок по
заголовку обновляет данные (они обновляются раз в минуту). Строки с данными старше 3 часов
приглушены. Окно, обновившееся после последнего снимка, показывает `new`: его использование ещё
ничем не подтверждено.

`limits.py` (стандартная библиотека) собирает данные там, где лежит набор; мод запускает его на
этой машине herdr (`source.json`, его пишет установщик). Настройки - раздел `[limits]` реестра:

| Ключ | Значение |
|---|---|
| `agents` | какие агенты и в каком порядке; по умолчанию `["claude", "codex"]` |
| `show` | `used` (0 % = ничего не израсходовано, по умолчанию) или `left` (100 % = всё осталось) |
| `[limits.commands]` | любой другой агент (Kimi, Cursor, Antigravity и т. д.): команда, печатающая `{"windows": [{"name", "used", "resets_at"}]}` |

Встроенные источники:

| Агент | Источник |
|---|---|
| Claude Code | `rate_limits` из входных данных statusLine. `limits.py statusline -- <прежняя команда>` оборачивает statusLine, хранит снимок каждой сессии и запускает прежнюю команду с теми же входными данными, поэтому видимая строка не меняется. Простаивающая сессия показывает последнее увиденное, возможно до сброса, поэтому по каждому окну выбирается самый поздний `resets_at`, а в нём наибольшее использование. Снимки собственной обёртки шаблона GSD также читаются. |
| Codex | `codex app-server`, `account/rateLimits/read`; при ошибке - последние `rate_limits` из журналов `~/.codex/sessions` |

## 3. Установка

```sh
herdr-app/install.py --dry-run --claude-statusline   # что будет изменено
herdr-app/install.py --claude-statusline
```

Установщик копирует оба мода, пишет `source.json` и в каждой пользовательской раскладке со штатной
боковой панелью переключает блок `spaces` на `space-groups` и добавляет блок `agent-limits` под
списком агентов. Раскладки Herdr доступны только для чтения; если есть только `main`, создаётся её
копия `kit`. `--claude-statusline` один раз оборачивает глобальный statusLine в
`~/.claude/settings.json` (резервная копия: `settings.json.pre-agent-limits`). Повторный запуск нужен
после обновления приложения или изменения `[limits] agents`. Удаление: вернуть блоку мод `spaces`,
удалить блок `agent-limits` и папки обоих модов.

Установщик шаблона GSD строит свою раскладку `gsd-mission-control` из `main` заново и сохраняет
блоки боковой панели, изменённые или добавленные другими установщиками, поэтому порядок установки
не важен.
