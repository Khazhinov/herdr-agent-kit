# Реестр MCP

[English](mcp-registry.md) | Русский

## Задача

Агент проекта со многими MCP-серверами загружает сотни схем инструментов в каждый запрос, а каждому
проекту нужна своя копия токенов.

## Решение

MCP-серверы остаются в папках, где они настроены, вместе с секретами. Реестр машины описывает каждую
папку один раз (модуль вида `mcp`). Проект хранит только имена инструментов и одну строку вызова.
Вызов уходит постоянному исполнителю в этой папке, обычно на самой дешёвой модели её поставщика;
агент проекта читает короткий файл ответа.

| Свойство | Как обеспечено |
|---|---|
| Контекст проекта не растёт | имена инструментов по модулям; параметры по запросу (`card <module> <tool>`) |
| Точные описания инструментов | `refresh` запускает каждый MCP-сервер из конфигурации самой папки и читает `tools/list`; LLM не участвует |
| Любая среда | встроены `claude`, `codex`, `opencode`; любая другая - `command`, `reset`, `mcp_config`. Формат конфигурации определяется по содержимому (`mcpServers`, `servers`, `mcp`, `[mcp_servers]`) |
| Дешёвая модель для вызовов | `model` и необязательный `effort` модуля |
| Секреты в одной папке | проект получает возможность, а не токен |
| Запись только с согласия человека | `--write` работает при `allow_write = true`; запрос помечается `WRITE ALLOWED BY USER` |

## Запись реестра

```toml
[modules.github]
description = "GitHub repositories, issues, pull requests, Actions runs"
workdir = "~/tool-agents/github"
runtime = "claude"
model = "haiku"
mcp = ["github"]                  # серверы, доступные исполнителю; нет поля - все
# tools = ["github:get_*"]        # фильтр инструментов для проектов
allow_write = false
```

Полный пример с пояснениями: `registry.example.toml`.

## Вызов

```bash
tool_ask.py ask github "list open PRs of repo X, fields: number, title, author"
```

Команда выводит путь к файлу ответа. Протокол, завершение и коды выхода:
[herdr-calls.ru.md](herdr-calls.ru.md). Карточка инструментов меняется только при `refresh` (он
запускает серверы), затем `sync` обновляет подключённые проекты:
[linked-projects.ru.md](linked-projects.ru.md).

## Особенности сред

Полный цикл (запуск, сброс, вызов MCP, файл ответа) проверен для Claude Code, Codex и OpenCode.

| Среда | Однократно для папки модуля |
|---|---|
| Claude Code | ответить на запрос доверия к папке при первом запуске |
| Codex | папка - доверенный проект (`[projects."<workdir>"] trust_level = "trusted"`), иначе её `.codex/config.toml` и MCP-серверы не загружаются; изменённые глобальные hooks однократно запрашивают доверие при запуске |
| OpenCode | разрешить запись ответов вне папки: `"permission": {"external_directory": {"<home>/.cache/herdr-agent-kit/**": "allow"}}` в `opencode.json` папки |
| Другая | `command` (полный argv с дешёвой моделью), `reset`, `mcp_config`, если конфигурация не в стандартном месте; проверить собственные запросы доверия и разрешения каталогов среды |

## Применение без этого кода

Вести таблицу папок с конфигурациями MCP, формировать перечень имён инструментов каждой папки из
`tools/list`, передавать проектам эти имена и одну команду, которая отправляет узкий запрос агенту,
запущенному в этой папке, и читать ответ из файла.
