# Changelog

## 0.1.0 - 2026-11-09

First tagged release. Requires herdr-core (`hc`, checked with 0.1.16); the older `herdr` terminal
multiplexer is not supported.

- MCP registry: one machine registry of folders with MCP servers, tool cards generated by
  `tools/list` (`mcp_probe.py`), narrow calls through a visible worker (`tool_ask.py ask`).
- Service repositories: typed functions declared in `agent-service.toml`, profiles with runtime,
  model and effort, synchronous and `--async` calls (`tool_ask.py call`, `wait`, `result`).
- Calls through herdr-core: persistent worker terminals per module, reset before each request,
  rules in the request, answer file with `DONE` or `FAILED`, exit codes, audit log.
- Linked projects: `.agent-tools/` index and per-module files, pointer line in the project's
  `AGENTS.md`, kept current by `sync`.
- Herdr App mods: `space-groups` (groups and subgroups of spaces) and `agent-limits` (usage limits of
  Claude and Codex), installer `herdr-app/install.py`, collector `limits.py`.
- Documentation: `concepts/herdr-launch.md` describes how any agent session starts another agent
  in its own Herdr App tab under the calling terminal (space and tab, flags, start checks, the check
  of the agent's command channel, waiting, cleanup) without the kit's code; README states that only
  herdr-core is used.
